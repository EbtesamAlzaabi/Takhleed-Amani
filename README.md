# 🌷 Takhleed Amani | تخليد أماني

## 💖 نبذة عن المشروع

**Takhleed Amani** هو مشروع ويب تفاعلي مصمم ليكون مساحة رقمية جميلة لحفظ وعرض الذكريات والمشاعر بطريقة أنيقة ومميزة.

يهدف المشروع إلى تقديم تجربة بسيطة ووجدانية تجمع بين الصور، الرسائل الخاصة، والروابط المميزة في صفحة واحدة يمكن مشاركتها بسهولة مع الأشخاص المقربين.

---

## ✨ مميزات المشروع

- 💌 صفحة ترحيبية بتصميم أنيق.
- 🖼️ معرض صور للذكريات.
- 💖 قسم للرسائل الشخصية.
- 🎁 إمكانية إضافة هدية أو رابط خارجي.
- 📱 تصميم متجاوب مع الهواتف والأجهزة المختلفة.
- 🌙 واجهة عصرية بتصميم Glassmorphism.
- 🔗 إمكانية مشاركة المشروع بسهولة عبر رابط مباشر.
- ⚡ مشروع خفيف وسريع ولا يحتاج إلى قاعدة بيانات.

---

## 🛠️ التقنيات المستخدمة
